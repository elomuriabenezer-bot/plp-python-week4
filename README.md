# Hands-On Lab - Grades, Eligibility & Smart Decisions

- `welcome.py` defines and calls a `welcome()` function to print greetings for three people.
- `toolbox.py` defines `double()`, `is_pass()`, and `greet()` and demonstrates each function.

I found `greet()` the most challenging because it uses a default parameter and combines multiple pieces of text in its return value. I checked that it uses the default greeting when none is supplied and the custom greeting when one is provided.
